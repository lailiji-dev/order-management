# 订单展示、手动编号与后台单价

2026-10-05 更新，沿用现有宝塔站点和共享 SQLite 数据库。

- 今日、明日订单卡片展示已填写的手机号，空手机号不展示。
- 今日、明日、所有订单各自保留手机号搜索条件，支持部分号码和忽略空格、括号、连字符。今日/明日可与取货状态筛选组合；所有订单搜索覆盖全部日期。
- 新增及复制订单的订单号为空且必填，可编辑已有编号。编号去除首尾空格，保留前导零，最多 100 字符，不允许控制字符。服务器在同一写事务中校验各设备间编号唯一，忽略大小写；取消及已取货订单也参与查重。删除订单后编号可再次手动使用，但已删除订单 ID 不能恢复。现存订单不会批量改号。
- 历史备份合并保留原有兼容行为，生成编号时跳过已占用编号。内部序列仅用于历史合并、创建顺序和新增人记录，不覆盖手动编号。
- 前台移除单价编辑入口及配方中的默认单价字段；管理员在 `/admin.html` 的“产品单价设置”保存，金额精确到分，支持零元。已有订单保留成交单价，新增或复制订单采用当前产品单价。
- `/api/admin/prices` GET/POST 要求管理员身份，POST 要求 CSRF。提交结构为 `{changes:[{id,beforePrice,price}]}`，价格以分表示；比较原价，发生并发冲突时整批回滚。员工即使有配比权限，也不能通过 `/api/sync` 改价。调价保留配方并记录审计。

验证：服务器实际 Python 3.6/SQLite 环境运行 16 项业务及 32 项安全检查；前端安全及交互检查、真实 API 双设备集成和独立浏览器移动端流程。发布会维护窗口备份并严格比较完整业务/账号/会话/权限/审计数据，再验证 HTTPS 路由及资源摘要。浏览器写入测试使用临时数据库。
