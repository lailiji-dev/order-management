# 食品厂订单与配比计算系统 — 第一版开发规格

> 文档用途：交给开发 Agent 直接作为第一版开发需求与验收依据。  
> 当前重点：先完成 **订单模块**，并预留/打通与 **配比计算模块** 的数据联动。  
> 使用场景：食品厂主管在手机、平板、电脑上录入订单、查看过去/未来订单、统计每日生产数量，并将生产数量发送到配比计算模块自动计算原料。

---

## 1. 项目目标

开发一个简洁、适合食品厂现场使用的生产管理网页。

系统包含两个一级模块：

1. **订单**
2. **配比计算**

底部主导航保持两个入口：

- 订单
- 配比计算

当前第一阶段重点完成订单模块，同时保留已经规划好的配比计算模块，并保证两者数据结构兼容。

### 1.1 核心业务流程

```text
新增订单
   ↓
按日期保存订单
   ↓
今日订单 / 日历查看全部订单
   ↓
自动汇总当天各产品订单数量
   ↓
主管可调整“实际生产数量”
   ↓
发送到配比计算
   ↓
根据每个产品的标准配方计算原料
   ↓
得到单品配料明细 + 当天原料总需求
```

# 8. 金额计算规则

系统增加产品单价设置。

所有产品统一按照：

```text
元/个
```

计价。

每个产品拥有：

```text
默认单价（元/个）
```

第一版不支持“元/盒、元/包、元/斤”等其他销售单位。

订单中每个产品：

```text
小计 = 数量 × 单价
```

整张订单：

```text
订单金额 = 所有产品小计之和
```

新增订单时填写：

```text
定金
```

只记录定金金额。

**不记录定金支付方式**，不需要现金、微信、支付宝等支付方式字段，也不需要为定金支付方式单独备注。

系统自动计算：

```text
还需支付 = 订单金额 - 定金
```

### 示例

```text
订单金额：¥680.00
定金：¥200.00
还需支付：¥480.00
```

## 8.1 校验规则

定金必须满足：

```text
0 ≤ 定金 ≤ 订单金额
```

第一版不考虑超额付款。

## 8.2 历史价格规则

非常重要：

订单保存时，需要把当时的产品单价保存到订单明细中。

不要只保存产品 ID 然后每次重新读取当前价格。

原因：

如果以后修改：

```text
小煎堆 0.50元 → 0.60元
```

以前已经创建的订单金额不能自动变化。

因此每个订单明细需要保存：

```text
productId
productNameSnapshot
quantity
unitPriceSnapshot
subtotal
```

产品价格设置仅影响：

- 新订单
- 后续新增加的订单产品

历史订单默认保留创建时的单价。

# 16. 取货时间规则

系统 **不设置独立的取货时间字段**。

原因：

- 有些客户不需要额外填写取货时间
- 取货时间属于可选信息
- 为了减少录单字段，统一填写在“备注”中即可

例如备注：

```text
王先生 138****8888
早上6:30取货，优先生产。
```

或者：

```text
下午取货
```

如果客户没有特别取货时间：

```text
备注可以留空
```

因此第一版不要开发：

- 独立取货时间输入框
- 取货时间选择器
- 按取货时间排序功能

# 32. 汇总规则

系统按当天所有有效订单统计产品数量。

例如：

订单 A：

```text
小煎堆 800
糖煎堆 500
```

订单 B：

```text
小煎堆 600
糖糍粑 300
```

自动汇总：

```text
小煎堆 1400
糖煎堆 500
糖糍粑 300
```

### 统计范围

参与汇总：

```text
该日期下所有未取消订单
```

“已取货 / 未取”只表示客户是否取走订单。

已经取货的订单不能因此从该日期历史生产总量中消失。

---

# 33. 订单数量与实际生产数量

生产汇总中必须区分：

```text
订单数量
实际生产数量
```

例如：

| 产品 | 订单数量 | 实际生产数量 |
|---|---:|---:|
| 小煎堆 | 1480 | 1500 |
| 糖煎堆 | 820 | 850 |
| 糖糍粑 | 500 | 500 |

默认：

```text
实际生产数量 = 订单数量
```

主管可以手动调整。

原因：

食品厂实际生产可能考虑：

- 损耗
- 备用数量
- 整批生产
- 临时调整

# 36. 配比计算模块

## 36.1 核心规则

成品按照：

```text
个数
```

计算。

不是按照成品公斤数。

每个产品拥有：

```text
标准配方产量（个）
```

例如：

```text
小煎堆
标准配方产量：500个

糯米粉：20kg
粘米粉：5kg
水：10kg
白砂糖：3kg
芝麻：2kg
```

今日生产：

```text
1250个
```

倍率：

```text
1250 ÷ 500 = 2.5
```

计算：

```text
糯米粉 = 20 × 2.5 = 50kg
```

公式：

```text
原料实际用量
=
实际生产数量 ÷ 标准配方产量 × 标准原料用量
```
